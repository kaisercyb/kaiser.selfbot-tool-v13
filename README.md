# What you need to use the Tool:

# 1. Node.js needs to be installed.

# 2. You need to use Termux from a computer terminal or phone.

# 3. Go to the Discord Developer Portal, create a bot, and then go to Rich Present and upload logos for games like Valorant, LoL, Minecraft, Standoff 2, and Red Dead Redemption 2 to get their Application IDs forehead

# 4. You need your Discord Token.

# Required Modules:

# Discord.js-Selfbot-v13

# Dotenv

# Readline

# child_process

# Setup:

# Simply navigate to the file directory and type "npm i" to download all modules.

# And finally, you can start the tool by typing `node index.js`.
